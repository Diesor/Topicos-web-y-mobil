# Lenguajes de programación y sus patrones de diseño

## Lenguajes orientados a objetos

### 1. Java
**Paradigma** Orientado a Objetos  

**Patrones de diseño:** Singleton, Factory Method, Abstract Factory, Builder, Observer (muy usado en Spring), Dependency Injection, MVC (Spring MVC)  

### 2. C#
**Paradigma** Orientado a Objetos

**Patrones de diseño:** Repository, Unit of Work, MVVM (WPF/.NET MAUI), Dependency Injection, Factory

### 3. C++
**Paradigma** Orientado a Objetos (multiparadigma: procedural, genérico)

**Patrones de diseño:** RAII, Factory, Singleton, Pimpl (Pointer to Implementation), Visitor

### 4. Django
**Paradigma** Orientado a Objetos (multiparadigma: imperativo, funcional)

**Patrones de diseño:** MVT (Model-View-Template), Decorator, Context Manager, Singleton

### 5. Ruby
**Paradigma** Orientado a Objetos

**Patrones de diseño:** MVC (Rails), Active Record, Convention over Configuration, Observer

### 6. Kotlin
**Paradigma** Orientado a Objetos (con soporte funcional)

**Patrones de diseño:** Builder (DSLs), Singleton (object), Delegation nativa

### 7. Swift 
**Paradigma** Orientado a Objetos (protocol-oriented)

**Patrones de diseño:** Delegate, Protocol-Oriented Design, MVVM (SwiftUI), Observer

## Lenguajes funcionales

### 8. Haskell

**Paradigma** Funcional puro

**Patrones de diseño:** Monad, Functor, Applicative, Composición de funciones

### 9. Elixir (con Phoenix)

**Paradigma**: Funcional (basado en Erlang/actor model)

**Patrones de diseño:** Actor Model, Supervisor Tree, Pipeline (operador |>), GenServer

### 10. Clojure

**Paradigma**: Funcional (Lisp)

**Patrones de diseño:** Inmutabilidad persistente, Software Transactional Memory, Composición

### 11. F#

**Paradigma**: Funcional (.NET)

**Patrones de diseño:** Pattern Matching, Railway Oriented Programming, Composición de funciones

### 12. Erlang

**Paradigma**: Funcional (concurrente)

**Patrones de diseño:** Actor Model, Let It Crash, Supervisor Tree

## Lenguajes multiparadigma

### 13. JavaScript (con React)

**Paradigma**: Multiparadigma (prototípico, funcional, orientado a eventos)

**Patrones de diseño:** Component Pattern, Hooks, Flux/Redux (unidirectional data flow), Observer, HOC (Higher-Order Components)

### 14. TypeScript (con Angular)

**Paradigma**: Multiparadigma (OO + funcional, tipado estático)

**Patrones de diseño:** Dependency Injection, MVVM, Module Pattern, Observer (RxJS)

### 15. Scala

**Paradigma**: Multiparadigma (OO + funcional)

**Patrones de diseño:** Monad, Type Class, Actor Model (Akka), Pattern Matching

### 16. Rust

**Paradigma**: Multiparadigma (sistemas, con influencias funcionales)

**Patrones de diseño:** Ownership/Borrowing (sustituye a patrones clásicos de gestión de memoria), Builder, Newtype, Trait Objects (Strategy)

### 17. Go

**Paradigma**: Multiparadigma (imperativo, concurrente, composición sobre herencia)

**Patrones de diseño:** Composición sobre herencia, Worker Pool, Pipeline (goroutines y channels), Functional Options

## Lenguajes declarativos / lógicos

### 18. Prolog

**Paradigma**: Lógico/declarativo

**Patrones de diseño:** Backtracking, Unificación, Recursión con listas

### 19. SQL

**Paradigma**: Declarativo (orientado a conjuntos)

**Patrones de diseño:** Query Object, Active Record (con ORMs), Data Mapper

## Lenguajes orientados a eventos / reactivos

### 20. Dart (con Flutter)

**Paradigma**: Orientado a Objetos con enfoque reactivo/declarativo en UI

**Patrones de diseño:** Widget Tree (composición), BLoC (Business Logic Component), Provider Pattern, State Management (Riverpod)
